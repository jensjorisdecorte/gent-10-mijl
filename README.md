# Gent 10 Mijl Tracker

Static PWA that follows Emilie (bib 944) and Charlotte (bib 4861) Wittamer on the MAES Gent 10 Mijl 2026 course.
Live data comes straight from the ACN Timing / Chronorace results API; positions between chip mats are projected from pace.

Deployed with GitHub Pages from the `main` branch root.
